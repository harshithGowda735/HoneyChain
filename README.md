# 🐝 HoneyChain

> Decentralized Beekeeping Management, Honey Traceability & Smart Hive Monitoring System.

HoneyChain is an Expo React Native mobile application built for beekeepers to manage colonies, monitor hive health, track honey harvest batches with QR-code provenance, record routine maintenance, and receive real-time colony telemetry alerts.

## 🌟 Key Features

- **Real-Time Telemetry**: Live colony internal temperature, humidity, and weight monitoring.
- **Stock Market-Style Weight Graph**: Clear visual trajectory of colony weight gain and nectar storage over time.
- **Native Phone Notifications**: Instant system alerts for high-temperature anomalies and temperature recovery.
- **Box-Specific Harvest Advisories**: Automated comb inspection recommendations based on sustained nectar accumulation.
- **Colony Maintenance Workflow**: Streamlined bi-weekly inspection and monthly cleaning checklist.
- **Honey Batch Provenance**: Complete traceability with public verifiable QR codes for honey consumers.
